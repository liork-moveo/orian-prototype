# Orian Express — prototype

A clickable prototype of the Orian Express delivery-tracking flow: 20 Hebrew RTL
mobile screens, wired end to end. Open `index.html`, or view it live at
https://liork-moveo.github.io/orian-prototype/

Everything is in one self-contained file — no build step, no dependencies,
images embedded as data URIs.

- Menu button (bottom left) — jump to any screen
- Back button (bottom right) — step back through the flow

Icons are from [Streamline Ultimate Light](https://streamlinehq.com), used under CC BY 4.0.
